# Data

## Source

**SemEval-2014 Task 4: Aspect Based Sentiment Analysis — Restaurant domain**
(Pontiki et al., 2014).

* ACL Anthology: https://aclanthology.org/S14-2004
* Official task page: https://alt.qcri.org/semeval2014/task4/
* Public mirror used for download: https://huggingface.co/datasets/alexcadillon/SemEval2014Task4

The dataset is released for research use. It is not redistributed here beyond
the original XML annotations required for the coursework demonstration.

## Raw files

| File | Description |
|---|---|
| `raw/semeval2014/Restaurants_Train_v2.xml` | Official training split (3,041 sentences) |
| `raw/semeval2014/Restaurants_Test_Gold.xml` | Official gold test split (800 sentences) |

Each `<sentence>` contains the review text, optional `<aspectTerm>` spans and
`<aspectCategory>` labels with one polarity per category.

## Processed files

Generated by `python -m scripts.prepare_data`:

| File | Rows | Description |
|---|---|---|
| `processed/train_sentences.csv` | 3,035 | One row per training sentence; binary aspect columns |
| `processed/test_sentences.csv` | 800 | One row per test sentence; binary aspect columns |
| `processed/train_aspect_sentiment.csv` | 3,511 | One row per (sentence, aspect) polarity annotation |
| `processed/test_aspect_sentiment.csv` | 973 | Same view for the test split |
| `processed/dataset_stats.json` | — | Descriptive statistics and integrity report |

Six exact duplicate training texts were removed (first annotation kept). The
test split is untouched. The `conflict` polarity is excluded from the
three-class sentiment task (195 training annotations, 52 test annotations,
~5% of categories); it does not correspond to a coherent polarity class.

## Label space

Aspect categories (SemEval names):

* `food`
* `service`
* `price`
* `ambience`
* `miscellaneous` (original name: *anecdotes/miscellaneous*)

Sentiment labels: `negative`, `neutral`, `positive`.
